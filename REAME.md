🌍 TradLive - Traduction en Temps Réel
Application de traduction vocale multilingue en temps réel supportant 16 langues.
🌐 DÉMO EN LIGNE
👉 Essayez TradLive : https://tradlive-app.onrender.com
✨ Fonctionnalités

🎤 Reconnaissance vocale en temps réel
🌍 Support de 16 langues
👥 Salles multi-utilisateurs (jusqu'à 10 personnes)
📱 Interface responsive (mobile/desktop)
🔊 Synthèse vocale automatique
📝 Mode texte de secours
📱 QR Code pour partage rapide des salles

🚀 Installation Locale

Cloner le repo
bashgit clone https://github.com/Dragonkalhan/TradLive.git
cd TradLive

Installer les dépendances
bashpip install -r requirements.txt

Lancer l'application
bashpython app.py

Ouvrir le navigateur
http://localhost:5000

💡 Comment utiliser

Choisissez votre langue sur la page d'accueil
Créez une salle ou rejoignez avec un code à 4 chiffres
Parlez dans votre langue - la traduction est automatique !
Partagez le QR code pour inviter d'autres participants

🛠️ Technologies

Backend: Python 3.x, Flask
Frontend: HTML5, CSS3, JavaScript (Vanilla)
APIs:

Architecture: Responsive design, Progressive Web App ready
